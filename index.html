    Connect OPUS-CAT to LoopCAT Web

    LoopCAT tried the standard OPUS-CAT addresses but the browser could not read a response. Use these checks in order.

    1. 1

      Check the OPUS-CAT engine

      Keep OPUS-CAT open, then open the engine check. A working engine shows a language-pair list such as ["en-tr"].

      Open engine check

      If the page does not load, start OPUS-CAT MT Engine and load the required model before testing again.

    2. 2

      Use a browser-readable OPUS-CAT build

      If the engine check works but LoopCAT still fails, the OPUS-CAT build is probably not sending the CORS permission required by browsers. Install or update OPUS-CAT from its official installation page.

      Open OPUS-CAT installation guide
    3. 3

      For an older engine, start the LoopCAT bridge

      From the extracted LoopCAT Web folder, run this command in PowerShell or Terminal and keep that window open:

      node scripts/opus-cat-web-bridge.cjs

      The bridge requires Node.js. If node is not recognized, install Node.js first. Leave LoopCAT's Base URL at http://localhost:8500; LoopCAT finds the bridge on port 8502 automatically.

    Fastest alternative: use LoopCAT Desktop, which includes the local compatibility layer and does not require the separate web bridge.
