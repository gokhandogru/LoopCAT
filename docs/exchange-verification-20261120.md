# LoopCAT Exchange development preview, 20 November 2026

The Exchange library uses LoopCAT’s theme, spacing, controls and keyboard focus. Examples show the type, language direction and purpose of each pack. Installed packs have search and type filters, with project activation and required checks visible on the pack cards. File previews put the publisher, license, trust and version information next to the install and export actions.

The terminology and QA forms group pack details, entries and sharing controls. A preview preserves the author’s editing copy, including any entries excluded from sharing. Version comparison works on selected project segments or bundled examples. A comparison leaves project activation alone and discards results when the selected version, project or segments change.

The Blind Translation Lab groups candidate texts, the rubric and the learner’s decision. It keeps the candidate order across reloads and moves keyboard focus to the revealed text or saved responses at the relevant step. Leaving a live comparison discards late results. AI workflow choices show the destination and data to be sent. The editor confirms whether a proposed draft was applied.

The private catalog guides users through trusting a publisher, opening a signed catalog, searching its listings and choosing an exact file. The signing tool can prepare reviewed pack files and their catalog in an empty release directory. The local rehearsal covers installing from the signed catalog, publishing a corrected version, withdrawing the previous version, and retaining requirements and translator-owned work.

The local web archive is built with `node scripts/build-web.cjs --dist <new-preview-directory>`. Extract it and open `index.html`. Example packs can also be exported from Exchange or generated with `node scripts/exchange-packs.mjs examples <directory>`.
