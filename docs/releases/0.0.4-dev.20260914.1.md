# LoopCAT 0.0.4-dev.20260914.1 — editing, archives, and workspace UX

This preview fixes regressions reported after the Resources update. It includes the startup fixes from the earlier 20260914 build.

- Atomic segment confirmation now participates in the same write ordering as autosave, undo, and redo. Confirmation uses a snapshot and preserves newer text typed while saving. Canceled pending saves cannot later overwrite a confirmed segment.
- Project ZIPs and workspace archives include resource definitions, TM contributions, term concepts, and term designations. The previous archive allowlist rejected these records with “Unsupported archive record store.”
- Checkpoint capture reads records in bounded batches instead of waiting for each record individually. Transactions still preserve atomic capture and rollback.
- Routine Saving/Saved notifications no longer interrupt editing or replace operation notices. Real persistence errors use error colors and remain visible until resolved; unrelated saves cannot dismiss a database error.
- Workspace contains Beginner Guide and About. Navigation stays stable when a long notification appears. The editor and inspector fit smaller windows, and advanced filters occupy less space.
- The packaged desktop smoke test now types and confirms two segments through the actual editor controls, then checks persisted targets and the absence of conflict copies.

Database schema 8, project-package schema 6, and backup schema 7 are unchanged. Fixes are in shared source used by Windows, macOS, Linux, and web. This local build does not replace published downloads. Native macOS/Linux and a multi-hour production soak remain separate release qualification steps; see the accompanying UX review for measured Windows-hosted renderer evidence.
