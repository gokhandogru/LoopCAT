# LoopCAT 0.0.4-dev.20260831 — unsigned preview

Prepared on 31 August 2026 for the next public preview. This version includes the final editor and AI-sidebar polish requested during desktop testing. It supersedes the earlier repository download mirror and does not replace the historical `draft-0.0.3` tag or its assets.

## Changes

- Completed success, failure, and information notices clear after two seconds or when changing screens, projects, or documents. Active operations and unsaved-work warnings remain visible.
- Project analysis dates, file headings, and counts have consistent spacing inside their containers.
- Provider settings opens an AI-only dialog. The normal project settings remain available separately.
- The AI sidebar exposes scope selection: selected segment, current document, whole project, filtered segments, or untranslated segments in the current document. AI actions use that scope and retain their confirmed/locked-text safeguards.
- The redundant Cloud suggestion button and top navigation Undo/Redo buttons are removed. Undo/Redo remain in the command palette and keyboard shortcuts.
- Dark mode now uses consistent slate surfaces, readable text and status colors, distinct controls, and visible teal keyboard focus across the editor, project screens, resources, sidebar, menus, dialogs, and Focus mode. Higher contrast, reduced motion, and forced colors are supported. Light mode is preserved.
- Release checks cover the revised behavior and both themes. Package-copy verification compares the current exported contents after backup restoration, including preserved source and target text and remapped IDs.
- The privacy rebuild on 31 August replaces personal computer paths in the internal review and planning prompt with repository-relative references, omits those document types from desktop packages, and adds an artifact check against their inclusion. The removed competitor research report is no longer part of the source snapshot. All three current downloads are rebuilt with a new source identity and checksums; application behavior is unchanged.

## Downloads and provenance

The supported set is the web application, Windows x64 installer, and Windows x64 portable application. Download the versioned ZIPs and checksum list from [downloads](../../downloads/README.md). Extract the selected ZIP before running it; the web version can also be served over HTTP/HTTPS for offline PWA installation.

All three archives contain the same `build-info.json`; the desktop payload also embeds it inside `resources/app.asar`. [release.json](../../downloads/release.json) records the exact source commit, full source-file fingerprint, artifact sizes, and SHA-256 hashes. Source files and documentation must remain unchanged between the web and Windows builds. A subsequent commit may publish only the generated download mirror: its verifier requires the original source commit to be an ancestor and every fingerprinted source byte to remain identical.

The source fingerprint covers root project files and the `.github`, `config`, `desktop`, `docs`, `i18n`, `icons`, `liquid-glass`, `scripts`, `src`, and `tests` directories. Downloads, local research reports, outputs, caches, and dependencies are excluded. Historical source provenance and formal signing gates remain unchanged.

## Verification and launch limits

The exact build results are recorded in [verification.md](../../downloads/verification.md). Automated accessibility and screenshot checks are evidence for the tested states, not a full manual accessibility certification.

Windows packages are unsigned because no signing certificate is configured. Windows may show an unknown-publisher or SmartScreen warning; no warning bypass is provided. Verify checksums and proceed only if you trust the source. Checksums detect corrupted or mismatched files but do not authenticate the publisher independently.

The repository remains private until its owner explicitly approves public visibility. A production-qualified release still requires Windows signing and clean-machine install/upgrade evidence. Native macOS and Linux downloads are not included in this set. Manual screen-reader, long-duration performance, permission-denied, and disk-full qualification remain outstanding. This preview must not be labeled a signed stable release.
