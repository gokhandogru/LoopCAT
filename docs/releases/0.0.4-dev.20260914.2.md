# LoopCAT 0.0.4-dev.20260914.2 — confirmation, protected tags, and view choices

Successful segment confirmation no longer displays the “Saved; Undo is available” banner. It uses the existing silent save acknowledgement while preserving confirmation, Undo, navigation, and actionable failure messages.

Protected tags keep their contents intact while the target segment is being edited. Whole tags can be selected, moved, or deleted; partial edits cannot damage their markup or attributes. Input validation also covers paste and noncancelable input before draft persistence.

Project, file, and resource listings offer Cards and List layouts. Choices are remembered per listing category, and switching preserves filters and actions.

This preview includes the fixes from 0.0.4-dev.20260914.1. Database and archive schemas are unchanged. Local builds do not replace published downloads.
