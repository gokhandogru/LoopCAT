# LoopCAT 0.0.4-dev.20261014.1 — TMX files in translation projects

This development preview adds TMX as an editable bilingual project document across the web, Windows, macOS and Linux applications.

## What changed

- Import `.tmx` files through **Import files** or **Other formats**, including mixed-format batches. Source text and existing translations appear in the editor's source and target columns.
- Choose **Draft** (default) or **Confirmed** for each TMX file's existing translations during import review. Missing translations remain empty and unconfirmed.
- Use the project's source and target languages to select TMX variants, regardless of their order. Exact locale matches take priority, with a unique same-language variant as fallback. Ambiguous variants or units without the project's source language produce an import error instead of silently selecting unrelated text.
- Export edited TMX through **Other formats** while preserving the source, other language variants, metadata, and original inline codes. Empty targets remain empty in bilingual exports.
- Update TMX source files using the existing review and version-history workflow. Project packages, backups and reopening retain imported text and segment status. The separate translation-memory **Import TMX** action continues to import memory entries.
- New import controls are localized in English, Turkish, Catalan and Arabic and support keyboard navigation and narrow RTL layouts.

The preview also includes the October 12 batch import, Statistics, file management, tag-aware matching and compact workspace improvements.

## Compatibility and installation

No storage or package schema change is introduced. IndexedDB schema 9, project package schema 7 and backup schema 8 remain in use. Earlier supported packages remain importable. Older application versions cannot reconstruct TMX project documents added by this preview.

Download application assets from this release, not GitHub's automatic source archive. Windows x64 offers installer and portable EXEs with ZIP wrappers. Web is a ZIP. macOS Apple Silicon offers DMG and ZIP. Linux x64 offers AppImage and DEB plus a ZIP containing both. Compare downloaded assets with the release's `SHA256SUMS.txt`.

Desktop packages remain unsigned development previews, and macOS packages are not notarized. Clean-machine installation and manual screen-reader qualification remain outstanding.

## Verification

The local TMX update passed all 1,545 unit tests, lint, type checking, formatting, localization validation, import boundaries and renderer build checks. Its production-renderer regression covers both import entry points, draft/confirmed status, missing targets, language direction and locale matching, duplicate units, malformed XML, UTF-16, inline codes, original-format export, source update history, project packages, backups, reload persistence, automated accessibility and narrow RTL layout.

The release workflow builds all four application variants from one repository revision, runs the existing platform verification gates, and runs the focused TMX workflow on Windows.
