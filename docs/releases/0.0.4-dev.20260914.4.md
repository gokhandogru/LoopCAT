# LoopCAT 0.0.4-dev.20260914.4

Normal desktop startup now opens the committed local database directly. Checkpoint reconstruction remains available for renderer-crash recovery and explicit recovery operations.

Projects appear before optional storage durability checks and workspace-folder scans. A bounded, local preview shows the last verified project catalog while the database opens; project actions become available after the current catalog has been read. An upgraded workspace without a catalog shows project metadata first and builds progress/count summaries in the background. Unknown counts display an ellipsis until ready.

The catalog stores project metadata and resource descriptors separately from document contents and translation units. Normal mutations update catalog counts in the same transaction. Restores, migration and recovery invalidate the catalog before rebuilding it.

Resources display names and counts without loading their entries. Opening a resource loads 100 entries at a time, with Previous and Next controls. Export and deletion explicitly read the complete selected resource. Obsolete page loads cannot replace a newly selected resource.

The shared renderer changes apply to web and desktop builds. Windows packages must be installed to update an existing installation. Native macOS and Linux qualification is separate from Windows validation.
