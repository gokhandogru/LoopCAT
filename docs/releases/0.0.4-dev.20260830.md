# LoopCAT 0.0.4-dev.20260830 — unsigned development preview

Prepared on 30 August 2026. This is the authoritative release record for the current web, Windows installer, and Windows portable downloads. It supersedes the untagged August 0.0.3 repository mirror. It does not replace or retag the historical `draft-0.0.3` release.

| Field | Meaning |
| --- | --- |
| Application version | `0.0.4-dev.20260830` in the package, PWA manifest, service worker, asset contract, and executable package. |

The source fingerprint covers root project files and the `.github`, `config`, `desktop`, `docs`, `i18n`, `icons`, `liquid-glass`, `scripts`, `src`, and `tests` directories, including new non-ignored source files. Generated downloads, reports, caches, build outputs, and dependencies are excluded. Dependency versions remain pinned by `pnpm-lock.yaml`. This is traceability for a local development snapshot, not a substitute for clean tagged source, platform signatures, or reproducible byte-for-byte installers.

## What this preview includes

- The August modernization: Electron 43, renderer sandboxing and secure fuses, modular application controllers/services, production/test isolation, and lazy feature loading.
- The Loopbird branding introduced on 7 August, semantic themes, density controls, responsive inspector, Focus mode, and grouped command palette.
- Bounded Undo/Redo, local Trash, separated save/job/error feedback, redacted local diagnostics, update activation, and expanded interface localization.
- The 25 August keyboard workflow and browser-safe correction: `F2` or `Ctrl/Cmd+Shift+P` for the command palette, `F4` for concordance, `Tab` Quick Insert, and protection for IME and AltGraph input. The [shortcut guide](../keyboard-shortcuts.md) is the binding reference; `Ctrl/Cmd+K` is not the primary palette shortcut.
- A distinct development version, common source fingerprint, embedded build information, build receipts tied to ZIP hashes, and a preparation gate that rejects mixed or stale source snapshots before replacing downloads.

The core offline editing, project recovery, translation-memory/terminology resources, QA/review, format support, and optional AI behavior remain unchanged by this release-preparation work. XLIFF 2.2 Core support predates the August modernization and belongs to the July history.

## Downloads and installation

Use the linked files in [`downloads/README.md`](../../downloads/README.md):

| Download | Contents and use |
| --- | --- |
| `LoopCAT.Web.0.0.4-dev.20260830.zip` | Extract and open `index.html`. Serve the folder over HTTP/HTTPS for service-worker/PWA installation; direct local-file use does not install a service worker. |
| `LoopCAT.Windows.Setup.0.0.4-dev.20260830.zip` | Extract and run `LoopCAT Setup 0.0.4-dev.20260830.exe`. |
| `LoopCAT.0.0.4-dev.20260830.Portable.zip` | Extract and run `LoopCAT 0.0.4-dev.20260830.exe` without installing. |
| `LoopCAT.0.0.4-dev.20260830.SHA256SUMS.txt` | Full SHA-256 hashes of the three ZIPs; use only with this download set. |
| `release.json` | Exact source identity, artifact names, byte sizes, and hashes for this set. |

Before opening a ZIP, compare its full SHA-256 with the same-named entry in the checksum list. PowerShell: `Get-FileHash -Algorithm SHA256 -LiteralPath 'path-to-downloaded.zip'`. Linux: `sha256sum -c LoopCAT.0.0.4-dev.20260830.SHA256SUMS.txt`. macOS: `shasum -a 256 -c LoopCAT.0.0.4-dev.20260830.SHA256SUMS.txt`.

The extracted `build-info.json` must match the identity in `release.json`. Windows packages are unsigned and may trigger SmartScreen or an unknown-publisher warning. No warning bypass is supplied; proceed only when you trust the source. Checksums detect corruption and mismatched files but do not independently authenticate a publisher.

## Verification and limits

The build pipeline validates the renderer and localization before packaging. Desktop staging embeds the source identity; Windows packaging writes a receipt only after both executables and ZIP wrappers finish successfully. Web packaging does the same for its ZIP. `pnpm run downloads:prepare` validates all receipts against the current source and exact archive hashes before updating the mirror. `pnpm run verify:repository-downloads` rechecks the generated manifest, source snapshot, complete download set, and checksums.

The source and artifact gates remain available through `verify:release`, `test:unit`, `verify:web-artifact`, `verify:web-smoke`, `verify:artifact`, `verify:desktop-smoke`, `verify:fuses`, and `verify:checksums`. The current local run results are recorded separately in [`downloads/verification.md`](../../downloads/verification.md); older modernization metrics are not presented as fresh results for this build.

Windows signing, clean-machine installation and upgrade testing, manual accessibility checks, and sustained reference-device performance qualification remain outstanding. This work does not supply signing credentials, certify security or accessibility, rebuild native macOS/Linux packages, or publish a GitHub release. The existing clean-tree/tag provenance, signing, and formal release-evidence gates are unchanged.
