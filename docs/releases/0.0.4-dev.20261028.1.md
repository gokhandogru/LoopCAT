# LoopCAT 0.0.4-dev.20261028.1 — matches, terminology and localization

This development preview updates the web, Windows, macOS and Linux applications.

## What changed

- The matches sidebar presents translation-memory and terminology results in compact rows. Double-click or press Enter to insert a result, and use the term context menu to edit or delete terminology.
- Fuzzy matches highlight word differences between the current source and the memory entry, with labels and distinct visual treatments.
- Select source text and use its context menu to add a term to the active termbase.
- Tag suggestions disappear as matching tags are inserted and return when an insertion is undone. Source, target and suggestion tags share a consistent design.
- The interface now supports Spanish (Spain). Catalan, Turkish and Arabic catalogs have been completed and reviewed, with improvements to translated layouts and mixed-direction text.

## Installation

Download the versioned application assets from the matching GitHub prerelease. Windows x64 offers installer and portable applications; macOS Apple Silicon offers DMG and ZIP packages; Linux x64 offers AppImage and DEB packages; and the web application is distributed as a ZIP. Compare downloads with the release's SHA-256 checksum list.

This is an unsigned development preview. The macOS application is not notarized, and clean-machine qualification across all platforms remains outstanding.

## Verification

The cross-platform preview workflow checks the source, browser workflows, packaged application startup, artifact contents, security fuses and checksums. The localization and editor checks cover dynamic placeholders and plural forms, Spanish language switching, and translated editor layouts.
