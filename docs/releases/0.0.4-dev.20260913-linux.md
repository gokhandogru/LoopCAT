# LoopCAT 0.0.4-dev.20260913 — Linux x64 preview

Linux packages supplement the existing Windows/web preview. No Apple enrollment or paid signing certificate is required. These remain development previews, not a stable or independently certified release.

## Download and install

Use the application assets on the [GitHub preview release](https://github.com/gokhandogru/LoopCAT/releases/tag/preview-0.0.4-dev.20260913), not GitHub's source-code archives.

- **Recommended for Ubuntu/Debian x64:** download `loopcat_0.0.4-dev.20260913_amd64.deb`.
- **Alternative Linux x64 package:** download `LoopCAT-0.0.4-dev.20260913.AppImage`.
- Download `Linux-SHA256SUMS.txt`, `Linux-build-info.json`, and `Linux-verification.md` from the same release.

With both packages and the checksum file in the same directory, verify them:

```sh
sha256sum -c Linux-SHA256SUMS.txt
```

If you downloaded only one package, compare its `sha256sum` output with that file's line in the checksum list. Checksums detect corruption; they do not independently authenticate the publisher.

Install the DEB from its download directory:

```sh
sudo apt install ./loopcat_0.0.4-dev.20260913_amd64.deb
```

Then open LoopCAT from the application menu or run `loopcat`. Back up existing projects before upgrading. To remove the application, use `sudo apt remove loopcat`; keep your project files and backups separately.

For the AppImage:

```sh
chmod +x LoopCAT-0.0.4-dev.20260913.AppImage
./LoopCAT-0.0.4-dev.20260913.AppImage
```

AppImage requires working FUSE 2 compatibility and a supported Chromium sandbox. On Ubuntu 24.04, the FUSE compatibility package is `libfuse2t64`. Prefer the DEB on Ubuntu if the portable package is blocked by namespace/AppArmor policy. Do not run LoopCAT as root or disable Chromium's sandbox to work around a launch failure.
