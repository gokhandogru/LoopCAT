# LoopCAT 0.0.4-dev.20260913 — Resources and recovery preview

Prepared on 13 September 2026 from the latest main-branch Resources 2.0 and reliability work. This unsigned development preview replaces the repository's August download mirror; historical releases and tags are preserved.

## What's included

- Optional Resource Settings during project creation, project-named defaults, one writable main TM, multiple reference TMs, configurable lookup priorities and penalties, and active/extra termbase contribution destinations.
- Stable resource identities, concept-oriented terminology, transactional main-TM confirmations, context and fuzzy matching, and local predictive typing from TM and terminology results.
- Quick term capture with Ctrl/Cmd+Shift+G; Tab accepts a visible predictive completion, while Alt+Insert explicitly opens Quick Insert for full alternatives.
- Hardened saving, ownership and recovery: pending-save barriers, conflict copies, verified archive backups, read-only windows, reversible restore, emergency export, and protected desktop credentials. See the saving-and-recovery guide in the repository documentation.
- Updated application/PWA/cache version labels and installation and editor guidance. IndexedDB uses schema 8, project packages schema 6, and backups schema 7; these schema numbers are separate from the application version.

## Downloads

The release provides the complete web ZIP, Windows x64 setup and portable executables, ZIP wrappers for both Windows applications, and SHA-256 checksums. The three ZIPs are also mirrored in the repository's downloads directory. Use application assets, not GitHub's automatically generated source-code archives.

- Web: extract `LoopCAT.Web.0.0.4-dev.20260913.zip` and open `index.html`. Serve the complete extracted folder over HTTP/HTTPS for installable PWA/offline-shell behavior; direct local-file use does not install a service worker.
- Windows installer: run `LoopCAT Setup 0.0.4-dev.20260913.exe`, or extract the matching Windows Setup ZIP first.
- Windows portable: run `LoopCAT 0.0.4-dev.20260913.exe`, or extract the matching Portable ZIP first.
- Verify each download against the SHA-256 list from the same release. Checksums detect corruption and mismatched files, not publisher identity independently of the trusted source.

Every ZIP carries the same build-info.json. The Windows payload also embeds that identity inside resources/app.asar. The release manifest records the source commit, complete source fingerprint, sizes and hashes. A later download-only commit publishes those exact artifacts without modifying the fingerprinted source.

## Qualification

These are unsigned Windows previews: Windows may display an unknown-publisher or SmartScreen warning. No signing certificate or independent clean-machine install/upgrade qualification is claimed. Native macOS and Linux packages are not included in this download set.

Exact checks and any host limitations are recorded in the downloadable verification.md and the repository's downloads/verification.md. Automated checks do not substitute for manual screen-reader testing, the full hardware/fault matrix, or long-duration reliability qualification. This is a prerelease, not a signed stable release.
