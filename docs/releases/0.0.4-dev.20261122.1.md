# LoopCAT 0.0.4-dev.20261122.1

Released 22 November 2026.

## Workspace design

The project navigation, editor, all five inspector tabs, Resources, Exchange, Statistics and supporting dialogs now share the updated teal palette, typography and controls. The inspector supports resizing and narrow screens, with keyboard navigation, light and dark themes, and Arabic layouts.

## XLIFF import and export

XLIFF imports can split aligned hard lines and blocks into editor rows. Blank lines and markup retain their position, and the import review offers a native-segment option. Native XLIFF boundaries are retained when bilingual alignment is uncertain or the file prohibits resegmentation.

Existing files can use **Files → Actions → Split XLIFF lines…**. The preview shows the new row count. Applying it carries over current translations and saves the previous rows, comments and history in Version history.

The revised exporter preserves original XLIFF content and metadata. The regression checks cover XLIFF 1.2, 2.0, 2.1 and 2.2, inline codes, CDATA, mixed content, unmatched segment markers, blank rows and edited targets.

## Statistics

The editor and Statistics use the same source word-count rules. HTML tags and layout-only rows contribute zero words. Source counts remain available during translation-memory analysis, with incomplete source or match coverage identified in the report.

Statistics opens for the current editor file or the files selected in Files. Project scope remains available. **Recalculate** refreshes an existing report, and **Retry analysis** restarts a failed analysis. Changes to project content or translation memories invalidate stale quotes. Saved snapshots retain their original file selection.

## Verification and installation

Local verification passed 1,760 unit tests, 63 bilingual interchange checks, XLIFF schema validation, and the packaged Windows and web smoke workflows. Two bilingual files were checked independently in the shipped web renderer, including each file, both files together and project scope. Counts agreed across native and split segmentation. The existing-project upgrade was also checked with an edited translation and its archived version.

Use the matching Windows installer or portable application, universal macOS DMG or ZIP, Linux x64 AppImage or DEB, or web ZIP from the [GitHub release](https://github.com/gokhandogru/LoopCAT/releases/tag/preview-0.0.4-dev.20261122.1). Verify downloaded files against its SHA256SUMS.txt.

This release uses the development preview channel. Windows packages are unsigned. macOS packages use ad-hoc signatures and require the steps in the [Mac installation guide](../macos-installation.md). Developer ID signing, notarization and the remaining production qualification checks are pending.
