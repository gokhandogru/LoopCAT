# LoopCAT 0.0.4-dev.20261106.1 — Update TM from confirmed segments

After importing a bilingual document, open it in the editor and choose **Segment tools → Update TM from confirmed segments…**. The dialog shows the destination memory and the number of eligible segments. Choose the active document or the entire project, then select **Update TM**.

The update adds confirmed source and target pairs to the project’s main translation memory and reuses existing pairs. It skips empty targets, missing protected tags, and incompatible imported language pairs. If you cancel or a save fails, completed updates are kept and you can rerun the action. The dialog is available in all five interface languages.

With the XLIFF example from [issue #10](https://github.com/gokhandogru/LoopCAT/issues/10), the first run adds five translations and skips four empty segments. A second run finds all five translations already in the memory.

This unsigned development preview includes the web application, Windows x64 installer and portable application, macOS Apple Silicon application, and Linux x64 AppImage and DEB. Use the release’s `SHA256SUMS.txt` to verify the downloaded files.

**Mac installation:** these ARM64 packages require Apple Silicon. They are not Developer ID-signed or notarized. Read the [macOS installation guide](../macos-installation.md), or save the [plain-text instructions](../../downloads/LoopCAT-macOS-INSTALL.txt), before opening the app. The guide includes the normal **Open Anyway** flow and temporary troubleshooting for older bundles with an invalid code signature.
