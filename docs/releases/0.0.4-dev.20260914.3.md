# LoopCAT 0.0.4-dev.20260914.3

Target segments keep protected tags visible as green, noneditable chips during editing. Whole tags can still be selected, copied, moved, or deleted. The original markup is preserved independently of each chip's displayed label.

Clicking a source tag or tag suggestion inserts it at the target selection and returns focus immediately after the inserted tag. Confirmation remains silent, with segment status showing the result.

This update replaces the target textarea with an inline editor across the shared web and desktop renderer. Windows installation requires the updated installer; an existing installed version does not change when the source is rebuilt.
