# LoopCAT 0.0.4-dev.20261115.1 — Formatting, Resources and Exchange

This development preview brings the recent file-format, resource-management and offline Exchange work into the Windows, universal macOS, Linux and web packages.

## Changes

- Word preserves native run properties, hyperlinks, content controls, bookmarks, fields and nested text boxes. Excel and PowerPoint preserve rich-text runs, cell and slide properties, relationships and untouched package parts.
- IDML/ICML preserve original style-run identities, whitespace, anchored objects and nested tables/footnotes. Invalid or ambiguous mappings fail explicitly instead of silently flattening formatting.
- File-format fixes cover bilingual XLIFF/SDLXLIFF, TMX/TBX, gettext, Qt, software resources, subtitles, HTML/XML and structured text. The import catalogue contains 55 supported extensions; support has format-specific limits documented in the review.
- Multilingual Excel provides column-aware import and target delivery with workbook and rich-cell formatting preservation.
- Dedicated TM/TB Resources editors add global search, paging, bulk edits with Undo, draft recovery and native desktop windows. Saving, recovery, QA completeness and terminology application also receive fixes.
- LoopCAT Exchange adds offline terminology, QA, workflow and teaching packs, pack authoring and the Blind Translation Lab.
- Retains universal Mac support for Apple Silicon and Intel, corrected ad-hoc signing and native-control layout fixes from November 9.

## Verification and limits

Before packaging, 1,730 unit tests, all nine browser suites and the file-format workflow checks passed locally. Native Word, Excel and PowerPoint reopened copy-source and translated fixtures: unchanged files were byte-identical, all 70 original package parts were unchanged, and source-copy renders had zero changed pixels. Translated fixtures preserved the tested native properties and untouched parts. IDML passed 20 structural checks; native InDesign rendering is unverified.

Translation length can still cause wrapping or overset. Chart caches, SmartArt, slide masters and embedded-object text are not newly extracted. Older projects with ambiguous edited rich-text mappings may need reimport. The Resources 100,000-entry cold-load target of under two seconds remains unmet on the reference Windows machine (3,375 ms in the final strict run). Windows WebKit checks do not qualify native Safari.

## Downloads and installation

Use the assets in [this release](https://github.com/gokhandogru/LoopCAT/releases/tag/preview-0.0.4-dev.20261115.1), including `SHA256SUMS.txt`. Windows has installer and portable ZIP/EXE packages; macOS has universal DMG/ZIP packages; Linux x64 has AppImage/DEB packages; the web ZIP runs after extraction.

Windows packages are unsigned. Mac previews are ad-hoc signed, not Developer ID-signed or notarized. Save `LoopCAT-macOS-INSTALL.txt`, verify the checksum, move the app to Applications and follow the [Mac installation guide](../macos-installation.md). This is a development prerelease, not a production-qualified release.
