# LoopCAT 0.0.4-dev.20260916.1

Routine target editing now stays quiet: inserting protected tags, terminology, translation-memory matches, copying source text, and editing Undo/Redo no longer display success notices. The target editor no longer shows the hovering shortcut tooltip; keyboard shortcuts remain available.

Import, export, AI operations, and actionable errors retain their notifications. Notifications float outside the page layout so showing or dismissing them does not move the translation workspace.

Includes the previous direct-file web compatibility fixes. Desktop packages remain unsigned development previews; macOS packages are not notarized.
