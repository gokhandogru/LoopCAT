# LoopCAT 0.0.3 — unsigned prerelease and repository mirror

LoopCAT `0.0.3` remains the current prerelease version. The binaries attached to the [GitHub prerelease](https://github.com/gokhandogru/LoopCAT/releases/tag/draft-0.0.3) were produced from historical tag commit `6f9754d` and are retained as that release's provenance record. The repository's [`downloads/`](../../downloads/) directory is a separately generated mirror rebuilt from the current code and therefore has different hashes. Always use the checksum file from the same location as the ZIPs.

The Windows packages are not digitally signed with Authenticode, so Windows may show an unknown-publisher or SmartScreen warning. Verify the ZIP files with `LoopCAT.0.0.3.SHA256SUMS.txt` and proceed only if you trust this repository. This remains a prerelease until signing and final clean-machine qualification are complete.

## Original Tagged-Prerelease Highlights

- Introduces the borderless Loopbird logo, shared web/PWA/desktop icon assets, the LoopCAT brand palette, and a reproducible icon-generation command.
- Adds XLIFF 2.2 Core import, generic handoff export, and current-file target reconstruction.
- Keeps XLIFF 2.0 and 2.1 Core compatibility.
- Supports Core hierarchy, notes, state, whitespace, `originalData`, and `cp`/`ph`/`pc`/`sc`/`ec`/`mrk`/`sm`/`em` inline content.
- Preserves skeletons, ignorable content, custom attributes, and Part 2/custom extension XML when rebuilding imported files.
- Adds separate XLIFF 1.2 and XLIFF 2.2 export actions and uses `application/xliff+xml` for XLIFF 2.x downloads.
- Adds offline OASIS-schema validation for a fixture and a live generated 2.2 handoff.

## Current Repository-Mirror Additions

- Upgrades the desktop runtime to Electron 43 with renderer sandboxing, secure fuses, hardware acceleration by default, and an explicit restart-based graphics fallback.
- Separates production and test renderer graphs and reduces root `app.js` to a 13-line bootstrap into checked feature controllers, services, stores, and lazy first-use boundaries.
- Adds semantic System/Light/Dark themes, Balanced/Compact density, a responsive remembered contextual inspector, Focus mode, and a keyboard-complete grouped command palette.
- Adds bounded Undo/Redo plus local Trash for reversible target, review, AI, pretranslation, structural, project, document, TM, term, and resource workflows.
- Adds separated save/job/notice/error presentation, actionable update activation, local-only redacted diagnostics, actionable empty states, DOM/Trusted Types hardening, and expanded Catalan/English/Turkish interface localization.
- Preserves the mature offline, format, package, workspace, QA, reporting, AI consent/redaction, and delivery safeguards under the full automated regression gate.

## Remaining Release Work

- Windows Authenticode signing and clean-machine evidence remain incomplete.
- Native CI has built and verified Linux AppImage/DEB artifacts, but checksum-authenticated clean-machine install/launch evidence is still required before formal publication.
- Current Windows and macOS release candidates still require external signing credentials; macOS additionally requires notarization and stapling. Every public artifact still needs recorded clean-machine evidence.
- LoopCAT preserves optional XLIFF Part 2 modules and custom extensions during current-file reconstruction, but it does not yet expose module-specific editing or author every Part 2 module in generic exports.
