# LoopCAT 0.0.4-dev.20261021.1 — AI input responsiveness and Statistics improvements

This development preview updates the Windows, macOS, Linux and web applications.

## What changed

- Hosted AI requests use an in-app consent dialog instead of a blocking native confirmation. Closing the dialog restores keyboard focus; requests wait for explicit acceptance and cancellation sends no text. This addresses a suspected cause of temporary typing interruptions reported after AI use.
- Statistics presents a revised analysis layout with match-category detail, configurable payable percentages, weighted words, price per weighted word and estimated costs. Pricing can be adjusted without repeating the underlying analysis.
- Placeholder handling respects PO format declarations for C, Objective-C, Python and Qt. Ordinary percentages remain editable where format metadata does not identify them as placeholders; editing, QA and export use the same contextual rules.

The preview retains TMX project-document import and export and the existing project, resource and backup workflows.

## Installation

Download the named application assets from this release. Windows x64 offers installer and portable EXEs, plus ZIP wrappers. macOS Apple Silicon offers DMG and ZIP packages. Linux x64 offers AppImage and DEB packages, plus a ZIP containing both. The web application is distributed as a ZIP. Compare downloads with `SHA256SUMS.txt`.

Desktop packages remain unsigned development previews, and macOS packages are not notarized, matching the previous release channel.

## Verification

The release workflow builds all four application variants from one source commit and checks quality, browser workflows, packaged startup, artifact contents, security fuses and checksums. Windows also runs the AI consent regression, covering acceptance, cancellation, Escape, focus restoration and immediate keyboard input in segment and terminology fields.
