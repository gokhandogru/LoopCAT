# LoopCAT 0.0.4-dev.20260922

Notifications no longer remain stuck over the workspace. Every notification now has an accessible close button, and error, conflict, warning, offline, invalid-input, and blocked-action notices automatically disappear after five seconds. Short success notices still clear after two seconds.

Dismissed save or storage errors remain available through LoopCAT's durability and recovery state, but routine autosave activity cannot immediately make the same dismissed banner reappear. Active operations and database initialization continue to report progress while they are running and can still be dismissed manually.

The notification behavior is covered by focused controller tests, including automatic expiry, manual dismissal, and suppression of duplicate durable errors. Desktop packages remain unsigned development previews; macOS packages are not notarized.
