# LoopCAT 0.0.4-dev.20260915.1

Fixes DOCX import, translation-memory analysis, QA, and regex search when the extracted web package is opened directly through index.html in Chrome. The previous web package attempted to create workers from file URLs, which Chrome rejects for its local-file origin.

The direct-file entry now embeds the three trusted worker programs and starts them through Blob URLs. Expensive processing remains in background workers, with the existing cancellation and timeout limits. Only packaged worker names and internally created Blob URLs are accepted. HTTP and desktop retain their external worker entrypoints and desktop retains its existing content-security policy.

The release gate now tests the actual production ZIP in Google Chrome through both file and HTTP URLs, in addition to the Electron checks. It imports and exports DOCX, checks translated content, creates a project, imports through the UI, edits and confirms a segment, verifies durable saving and workspace checkpoints, round-trips a backup containing the confirmed translation, and runs TM matching/analysis, QA, and regex. This gate reproduces the exact Worker SecurityError against the previous release and passes with this fix.

Includes the previous startup, recent-project preparation, protected-tag, and translator-workflow improvements. Download the complete new web ZIP and extract it before opening index.html. Existing browser workspace data is not deleted by this update. Desktop packages remain unsigned development previews.
