# LoopCAT 0.0.4-dev.20260923

## Arabic interface and editing

- Adds Modern Standard Arabic (**العربية**) throughout the application, with 2,672 translated source messages, Arabic plural handling, native desktop menu/save/recovery labels, and an offline Arabic Beginner Guide. Choose العربية from the Workspace language selector.
- Mirrors the interface for right-to-left use while keeping source and target direction independent. Improves narrow layouts, inspector keyboard navigation, resizing, protected tags, and access to the target editor at 200% zoom.
- Preserves Arabic diacritics, mixed Latin/Arabic text, and protected tags during editing and saving. QA recognizes Arabic-Indic digits and punctuation while continuing to detect changed values.
- Adds Arabic paragraph direction and proofing metadata to target DOCX files and localizes bilingual review headings.

## Verification

The local Arabic audit passed 97 captured interface states and 10 functional checks, with no reported clipping, horizontal page overflow, untranslated interface text, or axe accessibility violations in the tested editor. All 1,517 unit tests and static quality gates passed. The production Web ZIP passed direct-file and HTTP workflow smoke tests. See [Arabic localization](../arabic-localization.md) for test scope and editable catalog paths.

The release workflow builds and verifies Windows installer/portable, macOS Apple Silicon DMG/ZIP, Linux x64 AppImage/DEB, and static Web packages from the release source commit. Platform checks and checksums are required before attaching downloads to the GitHub prerelease.

Desktop packages remain unsigned development previews; macOS packages are not notarized. Automated checks do not establish complete clean-machine, screen-reader, or all-browser qualification. User content, external provider responses, and operating-system-owned dialogs retain their own language.
