# LoopCAT 0.0.3 — unsigned draft

This is an internal release candidate, not a production-qualified public release. The Windows installer and portable executable in this draft are unsigned because the repository does not currently have Windows Authenticode credentials configured. Version 0.0.2 remains the recommended published download until 0.0.3 is signed and its clean-machine evidence is complete.

## Highlights

- Adds XLIFF 2.2 Core import, generic handoff export, and current-file target reconstruction.
- Keeps XLIFF 2.0 and 2.1 Core compatibility.
- Supports Core hierarchy, notes, state, whitespace, `originalData`, and `cp`/`ph`/`pc`/`sc`/`ec`/`mrk`/`sm`/`em` inline content.
- Preserves skeletons, ignorable content, custom attributes, and Part 2/custom extension XML when rebuilding imported files.
- Adds separate XLIFF 1.2 and XLIFF 2.2 export actions and uses `application/xliff+xml` for XLIFF 2.x downloads.
- Adds offline OASIS-schema validation for a fixture and a live generated 2.2 handoff.
- Fixes the release signing verifier so the `pnpm run ... -- <platform>` argument form used by CI is accepted.
- Enables the pinned Electron install script explicitly through pnpm's build policy.

## Verified

- Release contract and i18n validation.
- OASIS XLIFF 2.2 Core schema validation.
- Full hidden-Electron browser suite: security policy, offline shell, smoke, regression, app workflow, workspace storage, package round trip, and large project.
- Packaged Windows desktop smoke and artifact verification are run after the artifacts are built.

## Remaining XLIFF work

LoopCAT preserves optional Part 2 modules and custom extensions during current-file reconstruction, but it does not yet expose module-specific editing or author every Part 2 module in generic exports. Additional interoperability fixtures from third-party CAT tools remain useful follow-up work.
