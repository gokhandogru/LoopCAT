# LoopCAT 0.0.4-dev.20261109.1 — Universal Mac packages and installation fixes

This development preview includes updated Windows, Linux, web, and universal macOS packages from the same source revision.

- Universal Mac DMG and ZIP support Apple Silicon and Intel.
- Mac previews are ad-hoc signed after Electron binary changes, with archive signatures and architectures verified.
- Native controls, toolbar/dialog wrapping, Spanish status labels, and Spanish/Catalan/Turkish sidebar tabs have been corrected.
- Native layout checks and fresh-runner launch tests cover Apple Silicon and Intel.

## macOS installation

These previews are not Developer ID-signed or notarized. Save **LoopCAT-macOS-INSTALL.txt** from the release assets. Verify your chosen installer against this release's **SHA256SUMS.txt**, move LoopCAT.app to Applications, eject the DMG, then use **System Settings → Privacy & Security → Open Anyway** after the first blocked launch. See the [full installation guide](https://github.com/gokhandogru/LoopCAT/blob/main/docs/macos-installation.md). Legacy re-signing instructions are troubleshooting only; re-signing does not change CPU compatibility.

Windows previews are also unsigned. This is a development prerelease, not a notarized production release.
