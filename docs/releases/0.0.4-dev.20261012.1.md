# LoopCAT 0.0.4-dev.20261012.1 — Batch import, Statistics, file history and compact workspace

This development preview brings the current round of translation and project-management improvements to Windows, web, macOS and Linux.

## What changed

- Import up to 50 mixed-format source files at once (100 MiB combined), review duplicates and encodings, and retry individual failures.
- Analyze Project, File, Selected files or Selected segments in Statistics. Switch between Simple and Advanced views for source words, exclusive repetition/TM categories, fuzzy bands, per-file and TM detail, and complete-search options. Save baselines and export CSV, HTML or JSON reports.
- Use a shared tag-aware linguistic counter and matcher across editor TM suggestions, Statistics and background analysis. Formatting differences no longer compete as raw tag-attribute edit distance. Match completeness and unsafe tag mappings are explicit; proprietary vendor score parity is not claimed.
- Rename, export, update, inspect version history and move files to Project Trash. Source update review protects prior translation history; restore creates a new head without erasing intermediate versions. Bulk recovery supports up to 50 files.
- Work in compact, coordinated editor toolbars with stable action slots, contextual selection, explicit Statistics scopes, overlay menus, a wider file selector, and primary Confirm beside Next unconfirmed. Project rows align checkboxes, names, counts, progress and Open/Actions controls. Shared patterns extend to Resources, Trash and dialog footers.
- New workspace labels support English, Turkish, Catalan and Arabic, including RTL and light/dark layouts.

## Compatibility and installation

Project history uses IndexedDB schema 9, project package schema 7 and backup schema 8. Earlier supported packages remain importable. Export a backup before opening production projects in a preview; older LoopCAT versions cannot read newer package schemas. The UI refinement itself introduces no additional schema change.

Download application assets from this release, not GitHub's automatically generated source archive. Windows offers an installer and portable EXE, each wrapped in a ZIP. Web is a ZIP. macOS Apple Silicon offers DMG and ZIP. Linux x64 offers AppImage and DEB plus a ZIP containing both. Verify assets against SHA256SUMS.txt.

Desktop packages are unsigned development previews; macOS packages are not notarized. Clean-machine and manual screen-reader qualification remain outstanding.
