# LoopCAT 0.0.4-dev.20261127.1

## Project sorting

Sort projects by creation date (newest or oldest first) or name (A–Z or Z–A). The selected order works alongside search and language filters and uses locale-aware name ordering. Project cards show their creation date and a separate update date when appropriate; older projects without a recorded creation date remain available.

## Audiovisual translation

Open an SRT, WebVTT or SBV document to use the collapsible **Video & timing** panel above the bilingual grid. Attach local video, translate in the grid and see accepted drafts immediately over the picture, including while paused. Replay or loop a cue, change playback speed, and use fullscreen preview. The Inspector remains available for the usual CAT tasks.

Edit timestamps directly or drag waveform boundaries. Timing locks, playhead boundary controls, nudging and target-side split/merge support cue editing while retaining imported source references. Timing edits participate in undo and project saving. Frame stepping is available when constant presentation intervals and decoding are verified; other media use millisecond controls. Editable general QA rules flag reading speed, line length, line count, duration, gaps and overlaps.

SRT, WebVTT and SBV exports use the approved target cue timings, including split and merged cues. WebVTT metadata is preserved. Invalid time ranges and unresolved timing or text-boundary conflicts block delivery. Project handoffs retain a portable media description, so recipients can relink their own video; video bytes and waveform caches are not included.

Other document formats retain their normal editor layout and shortcuts. The media decoder is loaded when a video is attached.

## Installation and verification

Use the matching packages and checksums from the [GitHub release](https://github.com/gokhandogru/LoopCAT/releases/tag/preview-0.0.4-dev.20261127.1): Windows installer/portable, universal macOS DMG/ZIP, Linux x64 AppImage/DEB, or web ZIP. The release workflow includes subtitle media editing alongside the existing quality, format, browser, accessibility and packaged-app checks. Completed build evidence is recorded in [download verification](../../downloads/verification.md).

This remains a development preview. Windows packages are unsigned; macOS packages use ad-hoc signatures without Developer ID signing or notarization. Follow the [Mac installation guide](../macos-installation.md).
