# Exchange development preview: what was exercised

This is a local development build based on `4459e39`. It has not been published as a LoopCAT release. The tested web archive identifies itself as `0.0.4-dev.20261106.1+source.6542c0ff5de6` and its SHA-256 is `2171fb19859046040686cd0e96970a4855ea9ddcece56226085374ed85cc788e`. The final quality run passed all 1,650 unit tests, lint, formatting, types and import boundaries. The renderer, release and localization checks passed (2,915 source messages).

| Area | Evidence | Remaining boundary |
| --- | --- | --- |
| Offline translator handoff | Two isolated renderer profiles author and transfer a terminology and a QA pack, preview, activate, copy a writable term, edit and confirm a target, then remove the pack while a real QA answer is pending. Uninstall keeps the learner's responses; sharing and deletion require their own actions. | Catalog and client kits | Tests verify independently anchored signatures, bytes and metadata, freshness, sequence, immutable versions and withdrawal by the correct signer. Kit tests cover partial selections, unavailable versions and project write conflicts. A failed activation cannot downgrade an existing required QA check. | The official catalog has no enrolled production signing identity or configured public origin. External maintainer rehearsal and signing-process review precede public submissions. |
| AI workflows | Instrumented providers inspect selected fields, request limits and destinations. Consent precedes requests and credential reads. Tests exercise stale segments, unavailable or changed providers, a failure during comparison, protected edits and declined sharing. Frozen lessons cannot read project context. | No paid provider call forms part of qualification. Costs are marked unknown when no estimate exists. |
| Turkish morphology | The developer-only Wasm guest accepts all 9 intended inflections and rejects all 9 near-misses on a small synthetic fixture. Abuse tests exercise time, memory, imports, outputs and cancellation. | This is neither an independently sampled Turkish corpus nor a qualified in-app executable host. All distributed packs are data only. |

To repeat these checks, run `pnpm verify:quality`, `pnpm verify:renderer`, `pnpm verify:exchange`, `pnpm verify:a11y`, `pnpm verify:arabic` and `pnpm verify:matches`. Use `node scripts/exchange-compute-probe.mjs` for the morphology comparison. The release workflow runs the Exchange lifecycle in each desktop CI environment; passing on one local Windows machine is not evidence of a macOS, Linux or Safari pass.

The extracted web ZIP, a warmed hosted Chromium PWA with its origin server stopped, and the locally packaged Windows application were also exercised. The offline PWA check observes service-worker document and script responses; the bundled pack gallery does not depend on a catalog. Windows qualification uses the unsigned local build, checks the ASAR and Electron fuses and launches the sandbox with GPU on and off. No store, production catalog or signed installer was published.

See [the paired performance measurements](exchange-performance-evidence-2026-11-06.md) for the machine, editor build, raw results and limits. The 100k trial exceeded the 10% relative input budget with 20 inactive packs; the 10k control also missed the existing 100 ms input budget. Keep the public release gated and repeat the full matrix on a quiet reference device before claiming performance qualification.
